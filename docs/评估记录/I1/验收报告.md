## 2. 冻结版本与配置

### 文档和索引

- 文档：A4 NIST AMS 400-1，SHA-256 `e0fff763cdbc652ed87d02e65b15f1c6e099b40addd4b3e379225da499dcf165`。
- 文档 ID：`e92d2975-fd02-4a38-9ee2-17a96c70341a`。
- 活动快照：`aa2f18a7-e193-4af8-a900-db62b3b61051`。
- Qdrant collection：`kb_default__iv_aa2f18a7-e193-4af8-a900-db62b3b61051`。
- 解析版本：`pymupdf-pages-v1`；分块版本：`paragraph-recursive-v1`。
- 分块目标/重叠/最小长度：900 / 120 / 120 字符。
- 实际上传至发布时间约 15.88 秒；该值只是本次本机样例记录，不作为性能承诺。

### 模型和检索

- LLM：DeepSeek `deepseek-flash`，非流式 JSON 输出，temperature 0.1，最大输出 8000 token。
- 嵌入：百炼 `text-embedding-v4`，1024 维，批大小 10。
- 重排序：百炼 `qwen3-rerank`。
- 稠密/BM25 top-k：20 / 20；RRF k=60；融合候选 30；重排候选 8。
- 上下文预算 5000 个估算 token；本轮相关性阈值保持 0，不在无基线时启用未校准过滤。
- Qdrant 服务端 1.15.4，客户端 1.15.1。

初次草案调用暴露了推理 token 计入输出上限的问题：3000 和 6000 token 均出现 `finish_reason=length`，导致 JSON 截断。调整为 8000 并限制草案最多 6 步、5 项质量检查、3 项安全提示后，冻结运行成功。已增加截断错误分类和不重试回归测试。
