# 样例文件与数据集适用性评估

本目录保存用于 Process-craft-rag 解析、检索和引用测试的外部样例资料。下载及校验日期：2026-11-18。文件仅用于教学和项目评估，不作为真实生产指导。

配套记录：

- [样例候选与下载记录](候选与下载.md)：本地 PDF、开放 HTML、中文网页、失败记录和后续下载约定。
- [中文开放工艺 RAG 相关数据集调研](中文开放数据集调研.md)：Mecha-QA、factory-ontology、KnowEval 等资源的匹配度、许可与使用决策。

后续所有样例候选、下载状态和数据集调研均在本目录维护，不再单独保留根级候选名单文档。

## 1. 结论

实际保留的 6 份 PDF 均可作为项目数据集，但用途不同：

- **第一次迭代单文档**：A4 NIST AMS 400-1。
- **快速冒烟测试**：A6 NISTIR 8127；需要完整流程时仍使用 A4。
- **多文档核心评估集**：A1 + A2 + A4，覆盖加工操作、质量/SPC、机内测量三个内容方向。
- **鲁棒性与扩展评估**：A5 用于图示和文本稀疏页面，A7 用于长文档及设计—制造综合内容。
- **不混入默认核心基线**：A5 的图示页较多，A7 篇幅长且含非商业许可限制，相关结果应单独报告。

这 6 份资料可以支撑英文 PDF 的解析、混合检索、引用溯源和多文档问答开发，但**不足以单独完成最终验收**：当前没有独立安全规范、独立材料手册、中文工艺 PDF 或真实企业工艺规程。

## 5. 建议的数据集划分

### 5.1 `i1_single`：第一次迭代

- **文件**：仅 A4。
- **原因**：69 页、全部页面有文本，内容同时包含定义、活动和步骤，便于控制首次联调规模。
- **验收重点**：上传至 `ready`、两路索引 chunk ID 一致、四阶段检索诊断、普通问答、结构化草案、引用核查和无答案拒答。
- **限制**：I1 通过只说明单文档技术链路成立，不代表多文档或完整工艺生成质量达标。

### 5.2 `parser_smoke`：快速回归

- **文件**：A6。
- **原因**：32 页且全部有文本，适合每次解析器、分块或索引改动后的快速回归。
- **建议检查**：页数、文本非空、标题路径、确定性 chunk ID、页码引用和少量固定问题。

### 5.3 `core_eval_v1`：多文档核心评估

- **文件**：A1 + A2 + A4。
- **选择理由**：满足项目“至少 3 份内容不同 PDF”的演示要求，同时覆盖加工、测量和质量控制。
- **建议首版 30 题**：A1 12 题、A4 10 题、A2 8 题。
- **题型要求**：单文档事实、精确术语/数值、跨页流程、多文档综合和无答案问题均应覆盖；多文档题只在一个主问题 ID 下计数，避免重复。
- **标注要求**：每题保存期望要点、必须引用页、是否应拒答和关联文档；检索指标另需相关页/块列表。

A7 不进入默认 `core_eval_v1`，以保持核心基线许可一致并控制文档规模。A5、A6 的结果作为专项补充，不用于冲淡核心集失败样本。

### 5.4 `robustness_ext`：扩展与压力测试

- **A5**：测试文本稀疏页、模型图、跨页上下文和引用稳定性。
- **A7**：测试 355 页长文档、跨章节综合和索引容量；仅在符合 CC BY-NC 4.0 的教学/研究场景使用。
- **报告方式**：与核心集分开列出解析成功率、耗时、失败样本和人工评分，不与 `core_eval_v1` 平均成一个总指标。

## 8. 后续必须补充的数据

1. **授权中文文本型工艺 PDF**：用于验证中文解析、中文分词和中文引用，不用跨语检索结果替代。
2. **独立安全与质量规范**：当前 A1 内含安全说明，但缺少独立安全来源，无法充分验证多来源安全结论。
3. **材料、刀具或设备资料**：补足材料选择、刀具参数和设备条件的跨文档查询。
4. **异常 PDF**：加密、损坏、纯扫描、无正文和复杂表格文件，用于验证失败状态与限制说明。
5. **领域确认样例**：至少一套经工艺人员确认的零件输入、加工指令模板和期望输出，用于判断结构化草案是否真正符合业务需要。

原始 PDF 应保持只读；解析文本、分块和索引写入项目约定的独立数据目录。引用页码使用 PDF 物理页码，从 1 开始。所有安全和工艺生成结果仍需工艺人员审核。
