## 6. 下载和入库约定

1. 下载到本目录内与内容对应的子目录；文件名使用英文小写和连字符，避免空格和特殊字符。
2. 下载中文件使用 `.part` 后缀，只有 `%PDF-` 文件头和打开校验通过后才改为 `.pdf`；失败时删除半成品。
3. 原始文件保持只读，解析文本、分块和索引写入项目数据目录，不覆盖样本原件。
4. 保存来源 URL、获取日期、许可、文件大小和 SHA-256；评估运行固定这些版本。
5. 公开可下载不等于允许再分发。CC 资料保留署名、许可链接和修改说明；`CC BY-NC` 不用于未经授权的商业场景。
6. 同一作品的 PDF 与 HTML 只选一个主版本，避免重复内容抬高召回。
7. HTML 采集限定域名和路径，遵守站点条款与访问频率，不无限制递归抓取。
8. 新工艺参数、安全要求和引用答案必须经人工复核；所有生成结果仍需工艺人员审核。
