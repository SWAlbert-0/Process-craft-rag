# 产品需求说明（PRD）

## 1. 产品概述

### 1.1 产品名称

Process-craft-rag：基于 RAG 的轻量级企业工艺生成系统。

### 1.2 产品价值

把分散在 PDF 中的工艺知识转化为可检索、可引用、可持续维护的问答与加工指令生成能力，减少人工查资料时间，并通过来源展示和证据不足拒答降低大模型误用风险。

### 1.3 成功标准

- 用户可独立完成“上传资料—等待索引—提问—核对引用”的闭环。
- 输出内容可追溯，且能区分文档事实、模型整理和缺失信息。
- 在固定人工评估集上达到团队确认的准确性与引用质量目标。
- 核心链路可配置、可测试、可复现。

## 2. 典型使用场景

### 场景 A：建立工艺知识库

管理员上传工艺规程 PDF，系统显示处理进度。若解析或索引失败，管理员查看原因并重试；处理成功后，文档进入可检索状态。

### 场景 B：生成零件加工指令草案

用户输入零件名称、材料、图号、关键尺寸和已知设备条件，选择“加工指令”模式。系统检索相关文档并输出结构化草案，每项关键结论带引用。信息不足时列出待补充项，不自行假设数值。

### 场景 C：连续追问

用户先询问某零件的加工流程，再追问“第二步的切削参数依据是什么”。系统将其改写成可独立检索的问题，返回答案并保留与上一轮的会话关系。

### 场景 D：核对证据

用户点击答案中的 `[1]`，侧栏显示文档名称、页码和原文片段；若原文仍存在，可进一步打开 PDF 对应页。

### 场景 E：效果评估

评估人员选择测试集和知识库版本，批量运行问题，逐项检查回答及引用，填写评分和备注并导出结果。

## 3. 信息架构与页面

### 3.1 登录页

- 字段：用户名、密码。
- 行为：登录成功进入会话页；失败显示统一错误，不透露账户是否存在。
- 会话过期后返回登录页，并保留可安全恢复的页面路径。

### 3.2 会话页

布局由会话列表、消息区、输入区组成，引用详情以抽屉展示。

**会话列表**

- 新建会话、按更新时间排序、重命名、删除。
- 删除需二次确认；删除后消息及引用快照按数据约定清理。

**消息区**

- 区分用户与助手消息，展示生成中、完成、失败状态。
- 助手消息展示正文、引用编号、引用列表及“需人工审核”提示。
- 加工指令模式按标题与表格/列表展示，不以不可解析的 Markdown 作为唯一数据来源。
- 失败消息允许重试；重试创建新的生成尝试，不复制用户问题。

**输入区**

- 模式：知识问答 / 加工指令。
- 支持多行文本、Enter 发送、Shift+Enter 换行。
- 可展开“检索范围”选择文档；默认全部可用文档。
- 生成期间禁止重复提交，可停止前端等待；是否中断服务端生成按 API 能力实现。

**引用抽屉**

- 显示序号、文档名、页码、片段、文档状态。
- 可复制引用文本；原文存在时支持跳转到对应页。
- 文档已删除时提示“原始文档已删除，以下为回答生成时的引用快照”。

### 3.3 文档管理页（管理员）

- 上传按钮与拖拽区，仅接受 PDF。
- 列表字段：名称、大小、页数、分块数、状态、上传人、更新时间、操作。
- 状态包括 `pending`、`parsing`、`indexing`、`ready`、`failed`、`deleting`。
- 操作：查看详情、重试、重建索引、删除。
- 重建或删除必须二次确认；重建期间旧索引是否可继续检索由架构设计中的版本切换规则决定。
- 详情显示失败阶段、脱敏错误信息、解析统计和索引版本。

### 3.4 评估页（首版可为管理员功能）

- 测试集导入：使用约定 JSON/CSV 模板，不在页面逐条维护复杂标注。
- 创建运行：选择测试集、配置版本和文档范围。
- 结果列表：问题、期望要点、回答、引用、评分、备注。
- 汇总：各指标均值/比例、失败样本数和运行配置。
- 导出 JSON 或 CSV，确保中文正常编码。

## 4. 关键交互流程

### 4.1 文档上传

1. 前端校验扩展名和大小，服务端再次校验真实文件。
2. 创建文档记录并返回文档 ID，前端进入状态轮询。
3. 后台完成解析、分块、嵌入、向量及 BM25 索引写入。
4. 状态变为 `ready` 后出现在检索范围中。
5. 任一步失败则记录阶段与原因，允许从安全阶段重试。

### 4.2 提问与生成

1. 用户提交非空问题；前端创建用户消息和生成中的助手占位消息。
2. 后端进行会话归属校验、问题改写、混合召回、重排序。
3. 无有效上下文时返回证据不足说明；有上下文时调用大模型。
4. 服务端保存正文、结构化指令、引用快照及运行元数据。
5. 前端完成渲染，用户可查看引用或继续追问。

### 4.3 删除文档

1. 管理员确认删除，文档立即退出可检索集合。
2. 系统删除或隔离索引，再删除原文件和解析数据。
3. 历史消息保留引用快照，打开原文时提示不可用。
4. 清理失败时记录后台错误并重试，不将文档恢复为可检索状态。

## 5. 加工指令输出约定

默认输出以下结构；未从输入或证据获得的数据填“待确认”，禁止猜测。

| 字段 | 说明 |
| --- | --- |
| `title` | 指令草案标题 |
| `workpiece` | 零件名称、图号、材料及已知条件 |
| `assumptions` | 用户明确提供或文档明确说明的前提，不包含模型暗自假设 |
| `missing_information` | 生成前仍需补充的信息 |
| `preparation` | 设备、工装、刀具、量具和资料准备 |
| `steps` | 顺序号、工序/工步、操作内容、设备刀具、参数、质量要求、引用 |
| `quality_checks` | 检验项目、尺寸或验收依据、引用 |
| `safety_notes` | 安全注意事项、引用 |
| `references` | 引用编号、文档、页码、片段 |
| `disclaimer` | 固定的工艺审核提示 |

当缺少材料、图纸、关键公差或设备条件时，系统仍可输出资料准备与待确认项，但不得生成看似完整且可直接生产的参数。

## 6. 引用展示规则

- 引用采用 `[1]`、`[2]` 编号，与当前消息一一对应。
- 引用编号由服务端根据实际上下文建立，模型不得创造新编号。
- 同一文档同一页的多个片段可分别编号，但 UI 可分组展示。
- 页码使用 PDF 物理页码，从 1 开始；若文档另有印刷页码，可作为后续扩展。
- 片段需保留检索原文，不展示模型改写文本冒充原文。
- 没有证据的内容不能附无关引用；无引用时明确为通用说明或缺失信息。

## 7. 异常与空状态

| 情况 | 产品行为 |
| --- | --- |
| 知识库为空 | 引导管理员上传，普通用户提示联系管理员 |
| 问题为空或超长 | 发送前提示，不调用接口 |
| 文档加密、损坏或无文本 | 标记失败并给出具体阶段；扫描件提示 OCR 尚未启用 |
| 没有检索结果 | 回答证据不足，并建议补充资料或改写问题 |
| 重排序或向量服务失败 | 本次请求失败并允许重试，不静默省略必要阶段 |
| 大模型超时 | 保留用户消息，助手消息标记失败，可重试 |
| 流式连接中断 | 前端标记结果可能不完整，以刷新后的服务端消息为准 |
| 无权限 | 隐藏管理入口，服务端仍执行权限校验 |
| 文档在提问后被删除 | 当前回答仍保留引用快照，原文链接失效并提示 |

## 8. 建议产品指标

- 上传任务成功率：按上传次数统计，目标不低于 95%（不含不合法文件）。
- 有效回答率：回答正确且引用可用的问题占比，建议目标不低于 80%。
- 引用可核查率：抽样引用能定位到真实原文的比例，目标 100%。
- 无依据参数率：出现无输入或证据支持的工艺参数的回答占比，目标 0。
- 人工评分、响应时延和失败率按评估与运维文档分别统计。

## 9. 后续可选迭代

- OCR、表格结构还原及图像理解。
- 按部门或项目隔离知识库和文档权限。
- 用户反馈、答案纠错和评测集回流。
- Word、Excel、HTML 等更多格式。
- PostgreSQL、独立任务队列和对象存储的规模化部署。
- 经审批的结构化工艺模板导出与业务系统集成。
