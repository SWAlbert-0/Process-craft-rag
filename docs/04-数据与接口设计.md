# 数据与接口设计

## 1. 约定

- API 前缀：`/api/v1`。
- 时间使用 UTC ISO 8601 字符串；ID 使用 UUID 字符串。
- JSON 字段使用 `snake_case`，与 Python/Pydantic 保持一致。
- 创建时间由服务端生成，客户端不能指定。
- 列表默认分页：`page` 从 1 开始，`page_size` 默认 20、最大 100。
- 错误响应不暴露密钥、服务器路径或堆栈。

## 2. 核心数据模型

以下为逻辑模型，具体字段可在数据库迁移中补充，但不得改变核心语义。

### 2.1 users

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | UUID | 主键 |
| username | string | 唯一登录名 |
| password_hash | string | 密码哈希，不出现在 API 响应 |
| role | enum | `admin` / `user` |
| is_active | boolean | 是否可用 |
| created_at | datetime | 创建时间 |

### 2.2 documents

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | UUID | 主键 |
| name | string | 原始文件名，展示前转义 |
| content_sha256 | string | 内容哈希，用于去重 |
| size_bytes | integer | 文件大小 |
| page_count | integer | 解析后的页数 |
| status | enum | `pending/parsing/indexing/ready/failed/deleting` |
| active_index_version_id | UUID/null | 当前可检索版本 |
| storage_key | string | 受控存储键，不直接暴露物理路径 |
| failure_stage | string/null | 最近失败阶段 |
| failure_message | string/null | 脱敏后的失败摘要 |
| uploaded_by | UUID | 上传用户 |
| created_at / updated_at | datetime | 时间戳 |

### 2.3 index_versions

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | UUID | 主键 |
| document_id | UUID | 所属文档 |
| status | enum | `building/ready/failed/retired` |
| parser_version | string | 解析器版本 |
| chunking_version | string | 分块配置版本 |
| embedding_model | string | 嵌入模型及版本 |
| embedding_dimension | integer | 向量维度 |
| qdrant_collection | string | 暂存或已发布集合名 |
| bm25_path | string | 受控索引存储键 |
| chunk_count | integer | 分块数量 |
| created_at / published_at | datetime | 构建与发布时间 |

### 2.4 chunks

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | string | 确定性分块 ID |
| document_id / index_version_id | UUID | 关联文档与版本 |
| ordinal | integer | 文档内顺序 |
| text | text | 清洗后的检索原文 |
| page_start / page_end | integer | PDF 物理页码，从 1 开始 |
| section_path | JSON | 标题路径，无标题时为空数组 |
| char_start / char_end | integer/null | 页内或文档文本偏移约定 |
| token_count | integer | 分块 token 估算或精确值 |
| metadata | JSON | 可扩展元数据 |

Qdrant payload 至少保存 `chunk_id`、`document_id`、`index_version_id`、页码；BM25 条目使用相同 `chunk_id`，确保融合与溯源一致。

### 2.5 ingestion_tasks

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | UUID | 任务 ID |
| document_id / index_version_id | UUID | 处理对象 |
| task_type | enum | `ingest/reindex/delete` |
| status | enum | `queued/running/succeeded/failed` |
| stage | string | 当前阶段 |
| attempts | integer | 已尝试次数 |
| lease_expires_at | datetime/null | worker 租约 |
| checkpoint | JSON | 已完成阶段与可恢复信息 |
| error_code / error_message | string/null | 脱敏错误 |
| created_at / updated_at | datetime | 时间戳 |

### 2.6 conversations 与 messages

`conversations`：`id`、`user_id`、`title`、`mode`、`document_filter`、`created_at`、`updated_at`、`deleted_at`。

`messages`：`id`、`conversation_id`、`role`、`content`、`status`、`structured_content`、`query_rewrite`、`model_name`、`run_config`、`request_id`、`parent_message_id`、`created_at`。

- `role`：`user/assistant`；系统提示词不作为普通历史消息暴露。
- `structured_content` 保存加工指令结构；普通问答可为空。
- `run_config` 只保存可复现的非敏感参数。
- `parent_message_id` 用于关联重试或生成尝试。

### 2.7 citations

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | UUID | 主键 |
| message_id | UUID | 所属助手消息 |
| label | integer | 当前消息内引用编号 |
| chunk_id | string | 原始分块 ID |
| document_id / index_version_id | UUID | 来源及版本 |
| document_name | string | 快照 |
| page_start / page_end | integer | 快照 |
| excerpt | text | 注入上下文的原文片段 |
| rerank_score | number/null | 重排序得分，仅作诊断 |

### 2.8 evaluation_runs 与 evaluation_results

- `evaluation_runs`：运行 ID、测试集版本、知识库快照/文档版本列表、配置、模型、状态、创建人和时间。
- `evaluation_results`：运行 ID、题目 ID、问题、期望要点、回答、检索诊断、引用、各人工评分、评语、评估人和评估时间。
- 人工评分与自动指标分字段保存，避免混淆。

## 3. 状态流转

```text
pending → parsing → indexing → ready
   │          │          │
   └──────────┴──────────┴→ failed →（重试）→ pending
ready →（重建，旧版本继续服务）→ ready（切换活动版本）
ready/failed → deleting →（物理记录清理或保留删除标记）
```

不允许 `failed` 或 `deleting` 文档参与检索。状态变更由服务端完成，前端不能直接写入状态。

## 4. 通用响应与错误

### 4.1 列表响应

```json
{
  "items": [],
  "page": 1,
  "page_size": 20,
  "total": 0
}
```

### 4.2 错误响应

```json
{
  "error": {
    "code": "DOCUMENT_NOT_READY",
    "message": "文档尚未完成索引",
    "request_id": "01...",
    "details": null
  }
}
```

常用错误码：`VALIDATION_ERROR`、`UNAUTHORIZED`、`FORBIDDEN`、`NOT_FOUND`、`DUPLICATE_DOCUMENT`、`DOCUMENT_NOT_READY`、`EMPTY_KNOWLEDGE_BASE`、`RETRIEVAL_FAILED`、`MODEL_UNAVAILABLE`、`OUTPUT_VALIDATION_FAILED`、`RATE_LIMITED`。

HTTP 状态遵循语义：400 参数错误、401 未登录、403 无权限、404 资源不存在、409 状态冲突、413 文件过大、422 内容校验失败、429 限流、502 上游模型错误、503 检索服务不可用。

## 5. API 一览

### 5.1 认证

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/auth/login` | 登录并设置会话 Cookie |
| POST | `/auth/logout` | 注销 |
| GET | `/auth/me` | 当前用户信息 |

### 5.2 文档（管理员写操作）

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/documents` | `multipart/form-data` 上传 PDF，返回 202 与文档/任务 ID |
| GET | `/documents` | 按状态、关键词分页查询 |
| GET | `/documents/{document_id}` | 文档与活动版本详情 |
| GET | `/documents/{document_id}/chunks` | 管理员分页查看分块 |
| POST | `/documents/{document_id}/retry` | 重试失败任务，返回 202 |
| POST | `/documents/{document_id}/reindex` | 创建新版本，返回 202 |
| DELETE | `/documents/{document_id}` | 下线并异步删除，返回 202 |
| GET | `/documents/{document_id}/content` | 受权读取 PDF；支持页码定位由前端处理 |
| GET | `/ingestion-tasks/{task_id}` | 查询处理进度 |

重复内容上传返回 409，并附现有文档 ID；是否允许同名由内容哈希而非文件名决定。

### 5.3 会话与消息

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/conversations` | 新建会话 |
| GET | `/conversations` | 当前用户会话列表 |
| GET | `/conversations/{id}` | 会话详情 |
| PATCH | `/conversations/{id}` | 重命名或修改默认模式 |
| DELETE | `/conversations/{id}` | 删除会话 |
| GET | `/conversations/{id}/messages` | 消息及引用 |
| POST | `/conversations/{id}/messages` | 非流式提问，便于测试与集成 |
| POST | `/conversations/{id}/messages:stream` | SSE 流式提问 |
| POST | `/messages/{id}/retry` | 重试失败的助手生成 |

创建消息请求：

```json
{
  "content": "请根据资料给出该轴类零件的加工流程",
  "mode": "craft_instruction",
  "document_ids": ["uuid-1", "uuid-2"],
  "client_request_id": "client-generated-uuid"
}
```

- `mode`：`qa` 或 `craft_instruction`。
- `document_ids` 省略表示全部可用文档；空数组视为参数错误。
- `client_request_id` 在会话内幂等，防止网络重试产生重复用户消息。

消息响应核心结构：

```json
{
  "id": "message-uuid",
  "role": "assistant",
  "status": "completed",
  "content": "……[1]",
  "structured_content": null,
  "citations": [
    {
      "label": 1,
      "document_id": "uuid-1",
      "document_name": "轴类零件工艺.pdf",
      "page_start": 3,
      "page_end": 3,
      "excerpt": "原文片段",
      "source_available": true
    }
  ],
  "request_id": "request-uuid"
}
```

### 5.4 SSE 事件

事件名统一为：

- `message_started`：用户消息 ID、助手消息 ID、请求 ID。
- `retrieval_completed`：候选数、引用预览、是否降级；不输出敏感内部路径。
- `content_delta`：文本增量。
- `message_completed`：最终完整结构化消息。
- `error`：脱敏错误码、消息和请求 ID。

连接断开后服务端尽量保存已完成结果；前端重新拉取消息，以 `message_completed` 或服务端持久记录为准。

### 5.5 评估

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/evaluation-runs` | 创建固定配置评估运行 |
| GET | `/evaluation-runs` | 运行列表 |
| GET | `/evaluation-runs/{id}` | 运行及配置详情 |
| GET | `/evaluation-runs/{id}/results` | 分页结果 |

| GET | `/evaluation-runs/{id}/export` | 导出 JSON 或 CSV |

## 6. 校验与安全

- 所有路径 ID 均校验资源归属；管理员操作仍需记录审计日志。
- 文件名仅用于展示，存储键由服务端生成，防止路径穿越。
- `document_ids` 数量设置上限，且不接纳未就绪文档。
- 问题长度、历史轮数、上传大小、导出规模均设限制。
- PDF 下载使用正确 Content-Type 和安全的 Content-Disposition。
- 评分接口校验评分范围和评估人权限。
- API 的 OpenAPI  schema 以后端实现为准生成，并在联调前与本文件核对。
