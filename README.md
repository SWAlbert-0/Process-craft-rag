# Process-craft-rag

基于 RAG 的轻量级企业工艺生成系统。

项目计划利用开源向量数据库和大模型 API，实现 PDF 工艺文档解析、分块、向量化存储、稠密与稀疏混合召回、重排序、多轮对话及引用溯源，最终生成供工艺人员审核的零件加工指令草案。

当前处于正式开发前的设计阶段，完整文档见 **[docs/README.md](docs/README.md)**。
