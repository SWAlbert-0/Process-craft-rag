# Process-craft-rag

基于检索增强生成（RAG）的轻量级企业工艺知识问答与加工指令生成系统。

项目对工艺 PDF 进行解析、分块和混合检索，结合大模型生成带有文档名、页码及原文片段引用的零件加工指令草案，并支持多轮对话和效果评估。

## 当前状态

项目按双周迭代推进，计划窗口为 **2026-11-09 至 2027 年 6 月**。第一次迭代为 **2026-11-09—11-22**，目标是使用真实文本型 PDF 跑通：

```text
PDF 解析分块 → 稠密/BM25 双路索引 → RRF 融合 → 重排序
→ 大模型生成 → 引用核查
```

当前仓库以设计文档、开发计划和样例数据准备为主。I1 启动决策及模型真实调用验证已完成，下一步进入工程初始化。完整范围、逐轮交付物和验收标准见[开发计划与风险](docs/开发文档/开发计划.md)，中期报告安排在下学期开学后的第 1—3 周。

## 使用边界

系统输出为 **AI 辅助生成的工艺建议，必须由工艺人员审核**，不可直接用于生产控制或替代正式工艺规程。缺少材料、图纸、公差或设备条件时，系统应明确标记待确认信息，不得编造参数或引用。

外部样例资料仅在各自许可范围内使用。公开可下载不等于允许再分发，正式演示包须保留来源、许可和必要署名。
